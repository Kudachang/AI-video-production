# AI Video Production

A working reference for AIGC (AI-generated content) video production — prompting techniques, tool-specific rules, and real production mistakes with fixes. Built for FUTURE™'s AI film pipeline (Seedance-primary, Higgsfield/Lovart cross-reference).

## ⚠️ This will go out of date — fast

AIGC tools change faster than most software. Model versions, platform rules, and even entire "hard constraints" documented here can shift or disappear within months. **Everything in this repo is dated.** Before trusting anything, check the date at the top of the file — if it's more than a few months old, verify it still holds before relying on it in production.

## Structure

- `TOOLKIT.md` — the main reference. General techniques + tool-specific hard rules + the full artifact/failure reference table.
- `ISSUE-LOG.md` — real production mistakes and their fixes, newest entry first.
- `projects/` — project-specific notes (character sheets, locked identity blocks, location anchors) — kept separate from the general toolkit above.

## How entries are ordered

Everything in this repo is **chronological, latest first.** New information goes at the top of each file, dated. Don't delete old entries — outdated info stays in place but should get a strikethrough or an "OUTDATED as of [date]" note rather than being removed, so the history of what worked when stays intact.
